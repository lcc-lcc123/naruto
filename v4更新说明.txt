映射 + AI 世界 v4.0.0 更新说明
================================

一、本次文件
- world.html   197,492 B  （核心更新，版本标记 world-v4.0.0）
- portal.html    5,211 B  （首页世界卡文案）

二、新增功能
1) 世界/时间存档
   - localStorage 自动保存（时间流动时每 15 秒）+ 手动保存/读取/重置
   - 保存内容：方块改动、玩家位置与朝向、地域、时间、速度、动物显隐
   - RLE 压缩，实测约 9.1 KB；刷新页面自动恢复

2) 温度驱动的相变
   - 水面 ≤ -1°C 结冰；冰 ≥ 1°C 融化；积雪 ≥ 2.5°C 消融
   - 雪天会在裸露地表降雪堆积（只铺一层，避免无限堆高）
   - 高度递减率 1.2°C/格，高山夏季可保留积雪

3) 反应库扩到 116 条
   - 新增 111 种物质（含 FeCl3、CuCl2、Na2O2、NaClO、HNO3、KMnO4、H2O2、葡萄糖等）
   - 增加“光照”条件
   - 反应台新增可搜索/按条件过滤的反应库，点击条目直接填入
   - 实测：116 条，无重复反应对、无缺失物质 id

4) 按周期表自动生成无机物
   - 化学面板新增“自动组合”标签
   - 选择中心元素（H/Na/K/Mg/Ca/Al/Fe/Cu/Zn/Ag/NH4/C/Si/N/P/S/Mn/Cr 等）
     与阴离子基团（O/Cl/S/OH/CO3/SO4/NO3/PO4），按常见化合价配平
   - 生成化学式、名称、元素质量占比；可一键加入反应台
   - 示例：Na2O、FeCl2、Fe2(SO4)3、Al2(SO4)3、(NH4)2SO4
   - 仅按化合价推演，未校验热力学稳定性

5) 动物随季节迁徙/隐匿的 3D 可视化
   - 每个地域 4 种代表动物，方块模型 + 名称标签
   - 顶级捕食者追逐草食动物；草食动物躲避捕食者；鸟类飞行
   - 冬季：部分物种隐匿/冬眠，鸟类与藏羚羊向南迁徙并在标签标注“迁徙”
   - 时序面板可开关“动物显示”

三、部署
1. 上传到 https://github.com/lcc-lcc123/naruto/upload
   - 必传：world.html、portal.html
   - 如果 GitHub 上还没有上一轮的 server.js（含 /world 路由）和 update2.sh，
     也一起上传：server.js（35,370 B）、update2.sh（2,223 B）

2. 服务器执行：
   cd ~/naruto-srv && sudo bash -c 'curl -fsSL -o ./update2.sh "https://lcc-lcc123.github.io/naruto/update2.sh?t=$(date +%s)" && bash ./update2.sh'

3. 核验：
   curl -s "http://101.200.171.33:3777/world?t=$(date +%s)" | wc -c
   # 应为 197492
   curl -s "http://101.200.171.33:3777/world?t=$(date +%s)" | grep -c "world-v4.0.0"
   # 应为 1
   curl -s "http://101.200.171.33:3777/world?t=$(date +%s)" | grep -c "反应库"
   # 应 >= 1
   curl -s "http://101.200.171.33:3777/?t=$(date +%s)" | wc -c

   curl -s "http://101.200.171.33:3777/m?t=$(date +%s)" | wc -c

四、说明与边界
- 存档只在本机浏览器，不跨手机/浏览器同步；清缓存会丢失。
- 相变是教学近似：不含潜热、盐度、流速、雪压密实等过程。
- 反应方程式与产物为教学简化，部分反应需特定浓度/温度/催化剂。
- 自动组合只按常见化合价配平，不判断热力学稳定性与真实存在形式。
- 动物为方块化代表模型，每个地域 4 种，不是完整种群模拟。
- 公元 0 年等远年节气日期使用简化太阳公式，可能有 1–2 天误差。
