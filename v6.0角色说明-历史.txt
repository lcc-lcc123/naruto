二、这次重做了什么
1) 人类 NPC 不再使用微方块点云
   - 之前的做法：半透明粗方盒底模 + 约 100 个微方块采样点。
     远看像人，近看是密集小点，正是你提到的“微方块细节”。
   - 现在的做法：直接复刻「中华人物图鉴 v2」的方盒骨架。
     头、五官、头发、头饰、上衣、下摆、腰带、配饰、手持道具
     全部由大块干净方盒拼装，近看是清晰的面/眼/眉/嘴/帽檐/衣纹，
     不再有微方块噪点。

2) 玩家忍者不再使用微方块点云
   - 直接复刻「暗影忍者 3D 角色」的方盒骨架：
     兜帽、面罩、怒眉、围巾与飘带、交叉皮革背带、金属扣、
     腰带、腰包、单侧肩甲、前臂/脚踝红缠带、灰色运动鞋、
     背后忍刀、可选短刀、披风。
   - 默认配色：玄夜（黑红）。另有青影 / 赤忍 / 白狼 / 沙隐，
     可用调试接口切换。

3) 100% 沿用参考包的参数与动作
   - 56 个民族 × 男/女 × 4 年龄段（儿童 7 / 少年 14 / 成年 26 / 长者 63）
   - 11 类职业 × 男/女
   - 人类 18 种动作：待机 / 行走 / 挥手 / 跳跃 / 拱手 / 鞠躬 / 舞蹈 /
     炒菜 / 问诊 / 讲课 / 敬礼 / 敲键盘 / 抡锤 / 拉锯 / 搬货 /
     操作台 / 巡检 / 讲话
   - 忍者 9 种动作：待机 / 步行 / 忍跑 / 潜行 / 拔刀斩 / 跳跃 /
     后空翻 / 结印 / 飞镖
   - 年龄会真实改变骨架比例：头高、躯干、腿长、臂长、四肢粗细、
     肩肘髋膝枢轴全部重算；长者有驼背角度，动作速度 0.82×。

4) 渲染结构（没有引入第二套渲染器）
   - 新增一个极小的场景图（Group / Mesh / Box / Cone / Cylinder），
     把参考包的 buildChar / buildHead / buildTop / buildExtras /
     buildNinja / ANIMS 原样移植进来。
   - 每帧在 CPU 上做关节矩阵计算，把方盒三角形写进世界现有的
     P_BLOCK 缓冲，与地形共用同一个深度缓冲，所以会被山体、树木、
     水面正确遮挡。
   - 没有加载 three.js（参考包各带约 670 KB 的 three.js），
     world.html 只增加约 72 KB；手机上不增加第二个 WebGL 上下文。
   - 人类/忍者使用不透明实体绘制；动物与植物继续使用原有微方块点云，
     两者互不影响。

5) 新增软阴影
   - 独立的轻量阴影着色器，在每个角色脚下画一个柔和的椭圆投影，
     解决“脚底浮空”的观感；不写入深度，不影响角色遮挡。

6) 新增查看与动作控制
   - 第三人称下，时钟条右侧出现「↺」按钮；点它或按 V，
     相机绕到角色正面，可看忍者正脸；再点回到背面。
   - Z：循环切换忍者 9 种动作；X：恢复自动（待机/步行/忍跑/跳跃）。
   - Shift + 移动：忍跑（速度 7.4，普通 4.8）。
   - 人类 NPC 会根据世界状态自动播放：行走 / 民族礼仪或舞蹈 /
     职业专属动作（教师讲课、厨师炒菜、医生问诊、军人敬礼等）。

五、边界（重要）
- 这是“把两个参考包的方盒骨架、配色、服饰、头饰、道具、
  年龄比例、关节动作原样移植进世界”，不是把 figures.html /
  ninja3d.html 的 three.js 页面嵌进来，也不是 photoreal 模型。
- 几何、颜色、动作、年龄参数来自参考包；光照使用世界自己的
  昼夜/天气/雾，因此正午、黄昏、夜里的明暗与参考包的摄影棚
  打光不同，这是有意的。
- 没有实现参考包的 three.js PBR 高光、实时投影阴影和刀光贴图；
  软阴影是近似椭圆投影。若要做到“参考包截图的 100% 打光”，
  需要再加一套 three.js/PBR 渲染层（约 1.4 MB 依赖）或在现有
  WebGL 里实现 PBR/阴影贴图，移动端开销会明显上升。
- 若目标是“更接近真实人物”，需要换 GLB/人物扫描模型与骨骼动画，
  已超出这两个方盒压缩包的范围；可以另开一条资产管线。
