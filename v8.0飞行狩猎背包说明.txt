一、本版新增
------------
1. 人物飞行模式
   - 手机点右下「飞行」，桌面按 G 切换。
   - 飞行中：按住「跳」上升，按住「挖（自动变“降”）」下降，摇杆/WASD 平移。
   - 再点「飞行」或按 G 退出；退出时若卡在方块内会自动向上浮出。

2. 跳跃高度提升
   - 起跳速度 8.2 → 11.2，实测垂直高度约 2.1 格（原约 1.3 格）。

3. 捕猎动物与战利品
   - 新增「攻击」键（手机右下红色按钮，桌面 F）。
   - 命中后弹出红色命中标记；动物 HP 归零死亡。
   - 玩家击杀才掉落：生肉、兽毛、羽毛、兽皮；大型动物额外掉兽皮。
   - 已驯服的动物不会被攻击，避免误杀宠物。

4. 游戏界面直接驯服与命令
   - 靠近动物 5.6 格内，画面上方出现「驯服 XX」按钮，点一下就驯服。
   - 驯服后同一位置出现指令：跟随 / 待命 / 坐下 / 进食 / 捕猎 / 逃跑 / 放归。
   - 捕猎指令只对肉食动物显示；所有指令即时生效。
   - 桌面 T 仍可驯服最近动物。

5. 快捷栏 + 背包
   - 快捷栏固定 8 格，背包 30 格，均可随世界存档。
   - 拾取/狩猎获得物品时：先补已有堆叠 → 再放空快捷栏 → 快捷栏满后自动进背包。
   - 点「背包」打开面板：
     · 点快捷栏物品 → 移入背包，空出该格；
     · 点背包物品 → 放入第一个空快捷栏格；
     · 快捷栏已满时提示先腾格。
   - 背包内可放武器、弹药、猎物材料与方块。

6. 武器系统（背包内初始各 1 把）
   - 石刀   近战    伤害 20  距离 3.0  冷却 0.45 s
   - 铁剑   冷兵器  伤害 30  距离 3.4  冷却 0.50 s
   - 长矛   冷兵器  伤害 26  距离 4.0  冷却 0.55 s
   - 猎弓   远程    伤害 26  距离 22   冷却 0.90 s  消耗箭
   - 火枪   枪械    伤害 46  距离 28   冷却 1.00 s  消耗子弹
   - 空手：伤害 7，距离 2.3。
   - 初始弹药：箭 ×20、子弹 ×12；弹药数量显示在左下信息框「手持」一行。
   - 攻击优先命中准星最接近的动物，再按距离排序。

7. 多点触控
   - 摇杆与攻击 / 跳跃 / 放置等按钮可同时按，互不抢占。
   - 右下按键改为 3×3：攻击 / 跳 / 放 / 挖 / 飞行 / 背包 / 看 / 原子 / 视角。

8. 放置按键修复
   - 之前「放」按钮的 data-act 是 put，而事件只认 place，导致按了没反应。
   - 现已同时兼容 put / place；选中方块后对准目标点「放」即可放置。
   - 选中武器/材料时点「放」会提示“武器 / 材料不能放置”，不会误放方块。

二、操作速查
------------
手机：
  左下摇杆移动；右下九宫格：攻击、跳、放、挖（飞行时变降）、飞行、背包、看、原子、视角。
  靠近动物 → 屏幕上方「驯服 XX」→ 指令按钮。
  打开背包 → 点物品双向搬运。

桌面：
  WASD 移动，空格跳（飞行中上升），Shift 加速（飞行中下降），
  E 挖，Q 放，F 攻击，G 飞行，B 背包，T 驯服最近动物，
  Z 切忍者动作，X 恢复自动，V / ↺ 看正/背面。

三、规则说明
------------
- 快捷栏 8 格、背包 30 格；方块为无限放置，武器/弹药/材料有数量。
- 背包满时新增战利品会提示“部分丢失”；请及时腾格。
- 驯服状态、生态个体仍不写入存档（刷新后动物会重新生成）；本次只新增
  物品栏、背包、手持物品与飞行开关的存档。
- 武器为教学化数值，不模拟真实弹道、穿透与后坐力；枪械为简化命中判定。
- 战利品直接进入物品栏，不在地上生成掉落物。

六、已知限制
------------
- 生态个体与驯服状态不存档（历史遗留）；刷新后需重新驯服。
- 物体碰撞只对玩家生效；动物可穿过部分地形。
- 远程攻击为简化命中判定，不处理遮挡与弹道下坠。
